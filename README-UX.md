# LinkHub v20 — UX Psychology Pass

Based on the referenced UX psychology video. The implementation focuses on ethical, practical UX improvements:

- Decision fatigue: fewer initial decisions, smart defaults, and contextual category suggestions.
- Goal gradient: honest progress indicators in Create Listing and Store setup.
- Reciprocity: browsing and the interested/cart flow remain usable without forcing signup first.
- IKEA/endowment effect: store setup reflects the user's information as it is built, creating a lightweight sense of ownership.
- Contrast/anchoring: avoided deceptive price anchors; the UI only shows seller-provided price/currency information.
- Loss framing: avoided manipulative urgency or fear-based prompts.

No SQL was changed in this UX pass.
